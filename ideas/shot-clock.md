# Shot Clock / Time Extensions

User's note: being blinded by a burst chalk bag means the player needs a **time extension**, which implies there is a time limit per throw.

*(suggestions)*
- Each throw has a turn-based "time budget" (counted in actions, not real seconds). It covers aiming, wind reads, chalking, and retrieving.
- Mishaps (blinded, soaked, searching for a disc) use up budget.
- Going over budget gives a time violation: a warning first, then a penalty stroke (as in real disc golf rules).
- A limited number of time extensions per round, which some skills or Swagger can increase.
