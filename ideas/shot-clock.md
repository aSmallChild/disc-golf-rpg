# Shot Clock and Action Points

## User's notes
- Being blinded by a burst chalk bag means the player needs a **time extension**, which implies a time limit per throw.
- In disc golf you get **30 seconds**. This could be represented by **action points (AP)**.
- You can use some equipment, then do a throw.
- A **Planned Shot uses more AP than a Standard Shot** (`aimed-shots.md`).

## Suggestions
*(suggestion)* **1 AP = 1 second, 30 AP per throw.** The number on screen then matches the real rule, and players understand it without explanation.

*(suggestion)* Example costs (to tune later):
| Action | AP |
|---|---|
| Standard Shot | 8 |
| Planned Shot | 18 |
| Chalk up (grip) | 3 |
| Wind read (chalk toss, grass toss) | 4 |
| Put on / take off sunglasses or hat | 2 |
| Swap disc | 3 |
| Pre-shot routine (lowers nerves) | 6 |
| Towel off (rain) | 3 |
| Cool-off breath (tilt) | 5 |

*(suggestion)* **Conditions and mechanics that change AP**:
- Mishaps take AP: blinded by chalk, hat blown off, sunglasses fall off.
- High nerves or tilt make every action cost a little more (fumbling, ranting).
- Skills and Composure reduce costs (e.g. "Quick Routine").
- Gear can cost AP to use but save AP elsewhere (a towel clip makes towelling faster).

*(suggestion)* **Going over 30**:
- First time: warning. Later: a penalty stroke, as in real disc golf rules.
- **Time extension**: a limited number per round. Some skills, Swagger, or events (blinded) grant one.

*(suggestion)* **Disc retrieval and searching** happen between throws, using a separate "search time" budget (real rules give 3 minutes to find a disc), so they don't compete with the throw clock.

## Critique
- **Fun**: AP turns gear into a budget puzzle ("chalk and a wind read, or a Planned Shot?"), which supports the "every item matters" principle. It's familiar from Fallout-style games and easy to read.
- **Challenge**: good, it's a planning challenge. The player trades preparation against precision every throw.
- **Risk: one dominant combo.** If one routine is always best, the choice disappears. Conditions (wind, rain, sun) should change which actions are worth it.
- **Risk: tedium.** Spending AP item by item every throw gets slow. A **saved routine** (e.g. "chalk + Planned Shot" as one click) keeps it quick.
- **Risk: penalty strokes for running out feel unfair** to new players. Show the remaining AP clearly and warn before an action would go over.
