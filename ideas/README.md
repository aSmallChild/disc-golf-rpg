# Ideas

One idea per file. Frontmatter holds `tags`, `status`, `related`.
*(suggestion)* marks AI-added content.

## Status
- `draft`: captured, not reviewed.
- `reviewed`: discussed, not yet decided.
- `accepted`: the user confirmed the **core idea**. AI suggestions inside stay unconfirmed until the user picks them.
- `rejected`: kept for reference.

## Tags
Only confirmed (`accepted`) ideas get tags. Add new tags here when needed.
| Tag | Meaning |
|---|---|
| `overarching-mechanic` | Affects every shot or the whole round (luck, nerves, tilt, golf-score skills) |
| `design-principle` | A rule that every feature or item must follow |
| `core-loop` | Part of how a single shot is played (aiming, feedback) |
| `content-pipeline` | How courses and content get made |
