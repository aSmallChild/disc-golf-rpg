# Course Design and Generation

User's notes:
- Be able to **design** courses and also **generate** them.
- Full generation is a nice-to-have. The immediate goal is to build courses manually.

*(suggestions)*
- Generated courses use the same format as hand-built ones, so they can be opened and tweaked in the editor.
- A partial-generation middle step: hand-place tee and basket, then generate terrain, trees, and regions between them.
- Seeded generation, so a course can be shared by its seed (e.g. a daily course for async multiplayer).
- Course themes driven by conditions: wooded, open field, mountain, lakeside, winter ice bowl.
